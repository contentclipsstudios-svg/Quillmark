# md2site — Test de démonstration

## Un seul fichier, un site entier
Ce **site statique** a été généré par `md2site.js` : zéro dépendance, un Markdown en entrée, un HTML autonome en sortie.

- Supporte les titres, listes, **gras**, *italique*, `code`
- Bloques de code multi-lignes
- Liens : [OpenClaw](https://openclaw.ai)
- Mode sombre automatique via CSS

## Prochaine étape
```
node md2site.js demo.md -o demo.html --title "Demo"
```
